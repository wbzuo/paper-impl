# MiniMind (custom small LLM with RLHF pipeline)

Link: [MiniMind project](https://github.com/jingyaogong/minimind)

This folder contains a compact language model implementation with pretraining, SFT, LoRA, DPO, PPO, GRPO, SPO, and distillation trainers.

## How to run

Prepare the expected dataset paths, then run one of the training scripts. For pretraining:

```bash
bash run_pretrain.sh
```
