# Dropout: A Simple Way to Prevent Neural Networks from Overfitting

Paper: [JMLR 15(56):1929-1958](https://jmlr.org/papers/v15/srivastava14a.html)

This folder implements a PyTorch dropout layer experiment.

## How to run

No standalone training entrypoint is defined yet. Import `dropout.py` from another experiment or add a small driver script.
