| Folder | Paper | Year |

| `bert/` | BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding | 2018 |
| `dropout/` | Dropout: A Simple Way to Prevent Neural Networks from Overfitting | 2014 |
| `droppath/` | Deep Networks with Stochastic Depth | 2016 |
| `minimind/` | MiniMind (custom small LLM with RLHF pipeline) | 2024 |
| `moe/` | Mixture of Experts (MoE) | - |
| `qwen_vl_ocr/` | Qwen-VL fine-tuning for document OCR | - |
| `resnet/` | Deep Residual Learning for Image Recognition | 2015 |
| `simclr/` | A Simple Framework for Contrastive Learning of Visual Representations | 2020 |
| `swin_transformer/` | Swin Transformer: Hierarchical Vision Transformer using Shifted Windows | 2021 |
| `vit/` | An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale | 2020 |

Additional notes and exploratory material remain in `notes/`, `papers/`, and `projects/`.
