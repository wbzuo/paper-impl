# Mixture of Experts (MoE)

Paper: [Outrageously Large Neural Networks: The Sparsely-Gated Mixture-of-Experts Layer](https://arxiv.org/abs/1701.06538)

This folder implements Mixture-of-Experts model components inspired by sparsely gated expert routing.

## How to run

No standalone training entrypoint is defined yet. Import `moe.py` from a model or experiment driver.
