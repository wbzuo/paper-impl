# BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding

Paper: [arXiv:1810.04805](https://arxiv.org/abs/1810.04805)

This folder contains a BERT fine-tuning script for IMDB sentiment classification using the ModelScope and Transformers training APIs.

## How to run

Prepare the dataset under `data/`, install the required ML dependencies, then run:

```bash
python train.py
```
