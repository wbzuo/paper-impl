# Qwen-VL fine-tuning for document OCR

Paper: [Qwen2-VL: Enhancing Vision-Language Model's Perception of the World at Any Resolution](https://arxiv.org/abs/2409.12191)

This folder contains utilities and scripts for fine-tuning a Qwen-VL style vision-language model on a document OCR task.

## How to run

Prepare image assets and JSON annotations, install the Qwen-VL fine-tuning dependencies, then run:

```bash
python train.py
```
