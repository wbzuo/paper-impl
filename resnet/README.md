# Deep Residual Learning for Image Recognition

Paper: [arXiv:1512.03385](https://arxiv.org/abs/1512.03385)

This folder implements ResNet-style image classification models and training utilities.

## How to run

Use the config-driven entrypoint:

```bash
python main.py --mode train --config configs/train_config.yaml
```

Additional project notes live in `docs/`.
